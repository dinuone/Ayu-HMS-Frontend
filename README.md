
# Ayu-HMS-Frontend

Ayu-HMS-Frontend is a modern and efficient Hospital Management System (HMS) frontend built using React.js and Vite. This project aims to deliver a seamless and user-friendly experience for managing hospital operations efficiently.

## 🚀 Technologies Used

React.js - A powerful JavaScript library for building dynamic user interfaces.

Vite - A fast and lightweight development environment for modern web projects.

Ant Design - A UI framework for elegant and responsive design.

Axios - For API requests and data fetching.

React Router - For seamless navigation.

## 📌 Features

🔹 User authentication & authorization

🔹 Role-based access control

🔹 Patient management

🔹 Doctor and staff management

🔹 Appointment scheduling

🔹 Medical records management

🔹 Billing & invoicing system

🔹 Responsive and mobile-friendly UI

## 📦 Installation

Follow these steps to set up and run the project:

### Clone the repository
`git clone https://github.com/your-username/Ayu-HMS-Frontend.git`

### Navigate to the project folder
cd Ayu-HMS-Frontend

### Install dependencies
`npm install`

### Start the development server
`npm run dev`

## ⚙️ Configuration

Ensure you set up the required environment variables in a .env file:

`VITE_API_BASE_URL=your_api_url_here`
